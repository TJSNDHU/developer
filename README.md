## What is ORA?

ORA is an autonomous AI software engineer. It connects to your GitHub
repo, reads your codebase, writes production-ready code, runs security
scans, and commits directly to your branches — all from your browser.

## Features Shipped (June 2026)

### 🛡️ Vanguard Security Scanner
- 25-pattern pre-commit security scan on every commit
- Detects: secrets, SQL/NoSQL injection, JWT replay, XSS, CSRF,
  path traversal, IDOR, missing auth, SSTI, ReDoS, LPDoS
- Critical findings block commit automatically
- Security badge in composer toolbar — always visible
- Red dot badge shows critical count at a glance
- Toast notification on sign-in if criticals exist
- **No other AI coding tool has this. Lovable had CVE-2025-48757
  (April 2026) because they don't.**

### 🔄 Loop Mode — Verified Execution
- Plan → Execute → Verify → Security Scan → Ship
- ORA shows plan first, user approves before any code written
- Files written one at a time, live progress shown
- ruff/eslint runs after every file — auto-retry 3x on failure
- Self-healing: ORA reads errors and rewrites code automatically
- Only commits after ALL steps pass
- Never gets stuck — 90s watchdog with StreamHealthPill feedback

### 🏥 Codebase Health Scanner (5 Categories)
- **Security**: 25-pattern Vanguard scan — 5 tokens
- **Performance**: N+1 queries, missing indexes, no pagination, SELECT* — 5 tokens
- **Code Quality**: dead code, large functions, missing error handling — 5 tokens
- **Dependencies**: CVEs, outdated packages, unused deps — 5 tokens
- **Database**: connection pool, missing indexes, hard caps — 5 tokens
- Full scan: all 5 categories — 15 tokens
- Dramatic health score (0-100) with urgency copy
- Individual fix buttons per finding — micro-satisfaction loop
- Blurred HIGH/MEDIUM findings create upgrade pressure

### ⚡ 4-Hop LLM Fallback Chain
- OpenRouter primary → DeepSeek direct → OR free chain → Groq emergency
- ORA never goes down even when individual providers have outages
- Provenance tags show which hop served each response
- Silent failover — user never notices

### 🧠 ORA Council — Self-Learning System
- ORA learns from every interaction across 5 modes:
  A: Chat logs | B: Advice | C: Code tasks | D: Debug | E: Audit
- Fine-tuning threshold: 1000 interactions
- Currently: 165+ interactions collected
- ORA gets better at YOUR specific codebase over time

### 🔐 JWT Hardening + Security Middleware
- JWT tokens include jti (unique ID) + iat (issued-at)
- NoSQL operator sanitizer (ASGI middleware) — blocks $where/$expr
- Request body size limit — prevents LPDoS
- Global unhandledrejection handler logging client errors

### 🎨 UI Polish
- Token-by-token streaming — responses feel instant
- Skeleton loading — no more "Loading 80%" bar
- Syntax highlighting with copy button on all code blocks
- Day/Night theme toggle (persisted in localStorage)
- StreamHealthPill — shows reconnect status above composer
- Inline loop progress bar: PLAN✓ → EXECUTE⏳ → VERIFY○ → SCAN○ → SHIP○
